## Drill #13: 아이템 모드 구현

LEC15 수업 예제와 제공 이미지를 바탕으로 아이템 선택 모드를 구현했습니다.
AI를 활용해 모드 연결, 공 선택 기능 구현 및 동작 확인을 진행했습니다.

### 실행

Python이 설치된 환경에서 저장소 폴더의 터미널을 열고 실행합니다.

```sh
python -m pip install -r Drill13/requirements.txt
python Drill13/main.py
```

학교 로고가 2초 표시된 뒤 타이틀 화면으로 이동합니다.

### 조작법

| 화면 | 키 | 동작 |
| --- | --- | --- |
| 타이틀 | Space | 게임 시작 |
| 타이틀 | ESC | 종료 |
| 게임 | 왼쪽 / 오른쪽 방향키 | 이동 |
| 게임 | Space | 선택한 공 발사. 수면 중에는 먼저 깨어남 |
| 게임 | I | 아이템 모드 열기 |
| 아이템 | 0 | 공 없음 선택 후 게임 복귀 |
| 아이템 | 1 | 작은 공 선택 후 게임 복귀 |
| 아이템 | 2 | 큰 공 선택 후 게임 복귀 |
| 아이템 | ESC / I | 선택을 바꾸지 않고 게임 복귀 |
| 게임 | P | 일시정지 |
| 일시정지 | P | 게임 복귀 |
| 게임 | ESC | 타이틀 복귀 |

아이템 모드는 플레이 화면 위에 선택창을 표시합니다. 선택 중에는 게임 진행을 멈추고,
복귀할 때 캐릭터와 기존 공을 유지합니다. 처음 선택은 작은 공입니다.

### 동작 확인

- 로고, 타이틀, 플레이, 아이템 및 일시정지 화면 렌더링
- 0/1/2 선택에 따른 발사 여부와 작은 공/큰 공 이미지 구분
- 아이템 모드 취소 및 플레이 상태 유지
- 화면 밖으로 나간 공 제거
- 타이틀 복귀 후 3회 재시작 시 오브젝트 중복 생성 없음
- ESC 및 창 닫기 종료 처리

SDL 소프트웨어 렌더러를 사용한 자동 동작 확인을 통과했습니다.
